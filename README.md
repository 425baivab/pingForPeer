# pingForPeer

A student-first community app with a ton of features that help enhance peer-to-peer connection and community engagement.

---

## Stack

This project uses:

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/) for fast builds and hot module replacement
- [ESLint](https://eslint.org/) for linting

---

## Dev Notes

This setup is based on the official [Vite React template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react), which includes:

- Fast Refresh with either Babel or SWC:
  - [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react)
  - [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc)

### TypeScript Support

To add type-aware linting and TypeScript integration, consider starting with the [Vite React + TypeScript template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts).
